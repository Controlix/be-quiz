# Feedback Inbox Guidelines

This directory is the intake location for **raw user test remarks, beta testing notes, and feedback sessions**.

### How to use this directory:
1. When a new testing round occurs or user feedback is exported from `/admin/feedback`:
   - Create a dated file: `YYYY-MM-DD-<session-or-topic>.md` (e.g. `2026-11-05-whatsapp-beta-testing.md`).
   - Record raw observations, member comments, and screenshot notes.
2. **Triage:**
   - Review each item and translate it into a structured requirement/feature in `docs/roadmap.md`.
   - Add a reference link in the session file pointing to the corresponding roadmap item.
3. **Never let completed historical items accumulate in the active roadmap:**
   - When a release milestone (e.g. `v1.1`, `v1.2`) ships and is verified, move the completed items into `docs/superpowers/feedback/archive-<milestone>-completed.md`.
